# The Dog Ate My Homework: Funniest Excuse — entry

A tiny deterministic program for the make.fun bounty
"The Dog Ate My Homework: Funniest Excuse"
(`u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c`).
Running `main.py` (Python 3.13, standard library only, no network) writes
one line — the excuse a dog gives after being caught eating the homework —
to `/output/entry.txt`. It runs identically every time.

## The entry

> It said 'show your working', so I showed it to my stomach — and it gave me full marks.

The dog takes the homework instruction "show your working" literally and
shows it to its stomach, which awards full marks. The dog is proud, not
sorry — a single line, 86 characters, no setup needed.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (86 characters, one line, UTF-8).
